# ТехноВыбор

Тестовый каталог ноутбуков, который принимает прайс-листы `.xlsx`, объединяет предложения по артикулу и даёт покупателям поиск по названию, артикулу и бренду. В проекте нет ИИ и внешних AI API.

## Возможности первой версии

- публичный каталог и карточки товаров;
- поиск по названию, артикулу и бренду;
- несколько предложений одного товара на одной странице;
- поставщик виден только внутри карточки товара;
- вход администратора по логину и паролю;
- проверка и импорт Excel-файлов;
- полная замена предыдущего прайса каждого поставщика;
- журнал последних импортов;
- встроенная база Cloudflare D1.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

На Windows создайте `.env.local` копированием `.env.example` и заполните значения вручную. Затем откройте `http://localhost:3000`.

## Excel-шаблон

Скачайте `public/technovibor-import-template.xlsx` или используйте кнопку в админ-панели.

Обязательные колонки:

| Колонка | Требование |
| --- | --- |
| Артикул | Непустой уникальный код товара |
| Название | Полное название ноутбука |
| Цена | Положительное число в тенге |
| Поставщик | Название поставщика |
| Бренд | Необязательно; может быть определён по словарю из названия |

Если в одном файле есть несколько поставщиков, система отдельно заменит прайс каждого из них. Строки с одинаковым артикулом объединяются в одну карточку товара.

## Переменные окружения

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=replace-with-a-strong-password
ADMIN_SESSION_SECRET=replace-with-a-long-random-secret
```

Файлы `.env*`, кроме безопасного `.env.example`, исключены из Git. Не добавляйте в репозиторий реальные пароли и прайсы.
