# ТехноВыбор

Каталог товаров, который принимает прайс-листы `.xlsx`, объединяет предложения по коду товара и позволяет искать по названию, артикулу, бренду, категории, описанию и распознанным характеристикам. Система работает на обычных правилах, словарях и регулярных выражениях — без ИИ и внешних AI API.

## Что уже работает

- публичный каталог, поиск и карточки товаров;
- закрытая админ-панель;
- автоматический поиск товарных таблиц на всех листах Excel;
- определение строки заголовков и колонок с названием, кодом, ценой, остатком и описанием;
- приоритет специальной цены в тенге с переходом на обычную цену, если специальной нет;
- категории из названий листов и строк-разделителей;
- извлечение процессора, оперативной памяти, накопителя, видеокарты, экрана и ОС из описания ноутбука;
- предпросмотр результата до изменения каталога;
- ручное исправление сопоставления колонок при неоднозначной структуре;
- сохранение профиля структуры поставщика для следующих загрузок;
- полная замена предыдущего активного прайса конкретного поставщика;
- журнал импортов и база Cloudflare D1.

## Как устроен импорт

1. Администратор выбирает `.xlsx` размером до 5 МБ.
2. Сервер читает все листы, оценивает заголовки и строит предпросмотр. Каталог на этом шаге не меняется.
3. Администратор проверяет поставщика, листы, количество строк, примеры товаров и выбранные колонки.
4. Если система ошиблась, нужную колонку можно выбрать вручную.
5. При подтверждении браузер повторно отправляет тот же файл. Сервер сверяет SHA-256, заново применяет правила и только затем обновляет каталог.

Один анализ действует 30 минут. Лимит — 10 000 распознанных товарных строк. Файл Excel не сохраняется в базе и не добавляется в Git.

## Поддерживаемые варианты Excel

Строгий шаблон не требуется. Система распознаёт распространённые варианты заголовков, например:

- `Название`, `Наименование`, `Описание`;
- `Артикул`, `ID товара`, `Код производителя`, `SKU`;
- `Цена`, `Дил. тг.`, `Спец.тенге`;
- `Наличие`, `Остаток`, `Склад`;
- `Бренд`, `Производитель`, `Категория`, `Гарантия`.

Если обязательные поля — название, идентификатор и цена — нельзя определить уверенно, импорт блокируется до ручного выбора колонок.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

На Windows создайте `.env.local` копированием `.env.example`, заполните значения и откройте `http://localhost:3000`.

## Переменные окружения

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=replace-with-a-strong-password
ADMIN_SESSION_SECRET=replace-with-a-long-random-secret
```

Файлы `.env*`, кроме безопасного `.env.example`, исключены из Git. Не добавляйте в репозиторий реальные пароли и прайсы поставщиков.
