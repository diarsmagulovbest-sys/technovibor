# Возврат из админ-панели в каталог

## Проблема

После импорта пользователь остаётся на странице `/admin`. В общей шапке есть ссылка на каталог, но на экранах шириной до 640 пикселей CSS скрывает обычные ссылки навигации. Кнопка «Выйти» завершает административную сессию и не возвращает в каталог, поэтому понятного пути назад на мобильном экране нет.

## Подтверждённое решение

- В заголовке авторизованной админ-панели разместить отдельную ссылку «В каталог» с адресом `/#catalog-title` рядом с кнопкой «Выйти».
- Ссылка должна быть видимой на мобильных и настольных экранах, доступной с клавиатуры и визуально отличаться от выхода из аккаунта.
- После успешного импорта показывать действие «Посмотреть каталог», ведущее на `/#catalog-title`.
- Не перенаправлять автоматически: администратор может захотеть загрузить следующий файл или проверить журнал.
- Не менять поведение кнопки «Выйти» и не менять административную авторизацию.

## Компоненты

- `app/admin/AdminConsole.tsx`: постоянная ссылка рядом с выходом.
- `app/admin/ImportAnalyzer.tsx`: ссылка после успешного импорта.
- `app/admin/AdminNavigation.tsx`: небольшие отображаемые компоненты двух действий для повторного использования и тестирования реального HTML.
- `app/globals.css`: группа действий и мобильная раскладка.
- `tests/admin-navigation.test.ts`: пользовательский контракт на отображаемый HTML — обе ссылки существуют и ведут в каталог.

## Проверка

- Новый тест сначала должен падать из-за отсутствия ссылок.
- После реализации должны пройти проектные тесты, полный набор тестов, линтер, проверка TypeScript и production-сборка.
- В опубликованной админ-панели ссылка должна быть видимой, а переход открывать секцию каталога на главной странице.
